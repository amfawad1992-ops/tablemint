# TableMint — Restaurant POS & Operations System

**Smart Orders. Smooth Service. Better Business.**

TableMint is a modern, full-stack Restaurant Management and Point of Sale (POS) system. It is designed for restaurants, cafes, and fast-food outlets to manage orders, tables, kitchen operations, inventory, and customer interactions seamlessly.

This project is built with a **React (Vite)** frontend, a **Node.js (Express)** backend, and a **PostgreSQL** database using **Prisma ORM**.

---

## ✨ Features

- **Admin Panel:** Complete POS, Orders, Kitchen Display, Table Management, Reservations, Payments, Menu Management, Inventory, Customers, Staff, and Reports.
- **Customer QR Menu:** Customers can scan a QR code at their table to view the menu and place orders directly from their phone.
- **Live Order Tracking:** Customers get real-time status updates on their device.
- **Printing:** Generate professional A6 QR Cards and thermal-style receipts.
- **Data Export:** Export data to CSV.
- **Discounts:** Apply dynamic discounts.
- **Responsive Design:** Works on desktops, tablets, and mobile.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite, Tailwind CSS, React Router, Lucide React, Recharts, qrcode.react.
- **Backend:** Node.js, Express.js, Prisma ORM.
- **Database:** PostgreSQL.
